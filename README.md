# Vínculo — Compañía virtual

MVP de compañera virtual configurable, aplicación web Next.js.

- Personaliza nombre, cómo te llama y estilo conversacional.
- Chat local con respuestas demo.
- Guarda perfil y conversaciones en localStorage del navegador.
- Responsive para teléfonos.

**Limitación de este MVP:** no está conectado aún a un modelo conversacional externo. Las respuestas actuales son reglas de demostración.

## Desarrollo
`npm install` y `npm run dev`.
