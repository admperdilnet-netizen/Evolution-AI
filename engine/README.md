# Evolution AI Engine

Independent, experimental self-hosted video-generation engine for Evolution AI.

## Safety boundary

- This module is developed on the `feature/evolution-ai-engine` branch.
- The production `main` branch and existing Magic Hour routes/UI are not modified by this scaffold.
- Do not route production generation traffic here until the worker is deployed, tested, and explicitly enabled.
- Never place provider API keys, model credentials, or worker secrets in source control or browser code.

## Initial architecture

```
Evolution AI web app (existing)
        |
        | future opt-in integration only
        v
Evolution Engine gateway (Next.js server route)
        |
        | private authenticated worker protocol
        v
GPU worker (Kaggle/Colab prototype initially)
        |
        v
Open-weight video model -> scene files -> FFmpeg assembly -> MP4
```

## Free-cloud reality

Kaggle/Colab GPU sessions are temporary and quota-limited. They are suitable for benchmarks and prototype jobs, not an always-on public production service. A free-tier worker may disconnect; jobs must be resumable and output files must be persisted outside the ephemeral session before the worker stops.

## Phases

1. **Isolation (this branch):** document boundaries and define the worker contract.
2. **GPU benchmark:** measure available free GPU VRAM, install time, model load, seconds per generated clip, and failure rate.
3. **Model selection:** choose an open-weight model only after hardware tests and license review.
4. **Worker:** implement authenticated job submission, status polling, cancellation, and durable result handoff.
5. **Media pipeline:** generate short segments, normalize dimensions/audio, concatenate, and validate MP4 output.
6. **Shadow testing:** test from a private/dev-only path without replacing Magic Hour.
7. **Opt-in rollout:** add an explicit engine selector only after acceptance tests pass.

## First acceptance target

A single short test clip generated by the open model on a free cloud GPU, returned as a playable MP4, with no commercial video-generation API involved. This is a benchmark target, not a promise of free unlimited service.
